About QuickNotes

QuickNotes is a simple application for capturing and managing your ideas.

  1. Firstly, add your quicknotes
  2. Mark it as done
  3. Then Delete a completed note
  • QuickNotes is built using HTML, CSS, and JavaScript.
  • It allows users to add, view, and delete notes.
  • The application is designed to be simple and user-friendly.
Shortcut Action
Enter Add the note
Ctrl + S Save the file in VS Code
